# Demo exchange

Clearly show the input method being used. Do not present typing as camera recognition.

1. Hearing person uses Listen: “Say hi to everyone!” Captions appear.
2. Sophia uses Spell: type “Hi guys! My name is ”, fingerspell SOPHIA, tap Add Letter for each recognized letter, review, then Speak.
3. Sophia types “Wow, that actually works!” and taps Speak.
4. Hearing person uses Listen: “It’s a good thing it does!”
5. Sophia types her own longer message and taps Speak. Example: “Sometimes it’s hard to share what I’m thinking with people who don’t know ASL. I want my thoughts and feelings to be heard.”
6. Hearing person uses Listen: “I’m glad we can talk.”

Whole-word sign recognition and automatic sentence translation are not implemented in this version. Library references are opened separately and do not translate arbitrary captions into ASL.
